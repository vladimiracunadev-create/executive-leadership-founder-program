# 📚 Bibliografía de referencia

> Este catálogo orienta el estudio. **No contiene ni distribuye copias de las obras**. Verifica edición, disponibilidad e idioma con el editor o biblioteca correspondiente.

## Cómo usar la bibliografía

- **Lectura A — Core:** estudia las secciones pertinentes en paralelo a la clase.
- **Lectura B — Contraste:** compara dos fuentes cuando existan escuelas o supuestos distintos.
- **Lectura C — Aplicación:** transforma la lectura en una decisión, cálculo, artefacto o experimento.
- **Lectura D — Fuente primaria:** regulación, impuestos, estándares, IA y datos vivos se revalidan en origen.

El programa no presupone que haya que leer los 229 títulos completos. Cada clase selecciona fuentes concretas y pide registrar **edición y páginas realmente consultadas**.

## Regla de copyright

Las obras se citan como referencias de estudio. El contenido original del repositorio sintetiza conceptos en redacción propia, construye casos nuevos y no reproduce capítulos ni extensos fragmentos protegidos.

## Trazabilidad

- El catálogo fuente vive en `data/books.csv`.
- El mapa `docs/REFERENCE_MAP.md` explica qué bibliografía gobierna cada parte.
- Cada `README.md` de clase contiene una **lectura comparada** y explica el uso de cada fuente seleccionada.
- `tools/validate_depth.py` impide que una clase vuelva a cumplir solo por tener una plantilla.
