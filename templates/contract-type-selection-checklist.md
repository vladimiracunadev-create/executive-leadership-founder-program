# Contract Type Selection Checklist — Chile

## A. Naturaleza de la relación

- [ ] Definí si existe prestación personal.
- [ ] Revisé subordinación y dependencia en los hechos.
- [ ] No estoy usando boleta, sociedad o nombre contractual para ocultar una relación laboral.

## B. Si es laboral: duración

- [ ] Indefinido: la necesidad es permanente o sin término objetivo.
- [ ] Plazo fijo: existe fecha cierta y revisé límite legal, renovaciones y alertas.
- [ ] Obra/faena: existe obra material o intelectual específica con hitos objetivos de inicio/término y no es labor permanente.

## C. Modalidad

- [ ] Revisé si la jornada es parcial (≤30 h) o de otra extensión.
- [ ] Definí presencial / distancia / teletrabajo / esquema híbrido jurídicamente documentado.
- [ ] Revisé turnos, exclusión/limitación de jornada o régimen especial si corresponde.

## D. Regímenes especiales

- [ ] Aprendizaje.
- [ ] Empresa de Servicios Transitorios.
- [ ] Agrícola/temporada.
- [ ] Casa particular.
- [ ] Transporte/marítimo/portuario/artes/deporte/educación u otro estatuto sectorial.
- [ ] Trabajo adolescente protegido, si aplica.

## E. Figuras no laborales o afines

- [ ] Honorarios/servicios independientes: autonomía real documentada.
- [ ] Proveedor/empresa: servicio empresarial real, no persona subordinada disfrazada.
- [ ] Práctica profesional: cumple requisito académico y artículo 8.
- [ ] Subcontratación: contratista autónomo + controles de empresa principal.
- [ ] Founder/socio/director que presta servicios: revisé estructura de control y hechos.

## F. Documentos

- [ ] Contrato correcto.
- [ ] Anexos necesarios.
- [ ] Registro electrónico aplicable.
- [ ] Jornada/asistencia.
- [ ] Remuneraciones y previsión.
- [ ] Teletrabajo, PI, confidencialidad y datos cuando proceda.
- [ ] Seguridad, RIOHS y protocolos aplicables.
- [ ] Alertas de vencimiento/renovación.

## G. Escalamiento

- [ ] RR.HH. valida operación.
- [ ] Contador/remuneraciones valida costo y cotizaciones.
- [ ] Prevención valida riesgos de seguridad.
- [ ] Abogado laboral revisa cualquier caso fronterizo, régimen especial o cláusula de alto impacto.
