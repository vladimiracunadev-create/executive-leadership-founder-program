# Primeros 90 días

No intentes estudiar 288 clases de forma pasiva.

## Semanas 1–4

Partes 00 y 01. Construye tu sistema personal y decision journal.

## Semanas 5–8

Partes 02 y 03. Practica memos, conversaciones difíciles y respuesta bajo presión.

## Semanas 9–12

Parte 04. Lidera un equipo real, comunitario, de proyecto o simulado con objetivos y 1:1.

## Regla

Cada semana debe terminar con una evidencia observable y una conversación de feedback.
