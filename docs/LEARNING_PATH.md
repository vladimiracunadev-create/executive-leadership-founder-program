# 🧭 Ruta de aprendizaje

## Ruta completa

1. **Etapa 1 — Autoliderazgo:** aprende a gobernar atención, criterio, comunicación y conducta.
2. **Etapa 2 — Equipo:** aprende a dirigir personas, proyectos y operaciones.
3. **Etapa 3 — Negocio:** aprende KPI, finanzas, ventas y marketing.
4. **Etapa 4 — Dirección:** aprende producto, estrategia, organización y riesgo.
5. **Etapa 5 — Alta dirección:** integra empresa, directorio, capital y tecnología.
6. **Etapa 6 — Propiedad:** crea, formaliza, escala y reduce dependencia personal.

## Ritmo sugerido

- 4 clases por semana × 2,5 h = 10 h/semana.
- 72 semanas para 720 horas.
- Cada tercera clase debe producir un artefacto visible.
- Cada parte cierra con proyecto integrador.
- Cada etapa cierra con defensa.

## No saltar por cargo

Tener años de experiencia o un título no reemplaza una evidencia. Se puede acelerar una clase mediante un **challenge test**, pero la competencia debe demostrarse.
