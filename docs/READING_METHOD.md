# Cómo usar libros, papers y fuentes sin convertir el programa en un resumen de libros

Los libros son **andamios conceptuales**, no contenido para copiar. Cada clase sigue este proceso:

1. identifica una pregunta profesional concreta;
2. triangula al menos dos autores o marcos cuando existen enfoques distintos;
3. extrae principios, distinciones y criterios de decisión en redacción original;
4. conecta esos principios con evidencia o estándares cuando corresponde;
5. construye un ejemplo nuevo y verificable;
6. termina con una decisión o artefacto profesional;
7. conserva la referencia para que el estudiante pueda profundizar en la obra original.

Cuando una fuente es normativa —por ejemplo Dirección del Trabajo, SII, NIST, OECD o IFRS— la fuente oficial tiene prioridad sobre un libro secundario. Cuando la materia admite escuelas distintas —liderazgo, estrategia, cultura, negociación— la clase presenta los trade-offs y evita vender una escuela como ley universal.
