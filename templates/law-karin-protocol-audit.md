# Ley Karin — Audit de preparación gerencial

## Prevención

- [ ] Política/protocolo vigente y accesible.
- [ ] Riesgos psicosociales y de violencia considerados en prevención.
- [ ] Jefaturas capacitadas para reconocer señales y no investigar informalmente.
- [ ] Canal de denuncia conocido.

## Recepción

- [ ] Existe responsable de recepción y escalamiento.
- [ ] Medidas de resguardo pueden activarse rápidamente.
- [ ] Confidencialidad y no represalia están diseñadas.

## Investigación / proceso

- [ ] Procedimiento y responsables definidos.
- [ ] Plazos se verifican contra normativa vigente.
- [ ] Evidencia se conserva de forma segura.
- [ ] Conflictos de interés tienen ruta alternativa.

## Cierre

- [ ] Decisiones y medidas correctivas quedan documentadas.
- [ ] Se revisan causas sistémicas, no solo personas.
- [ ] Se actualiza prevención y capacitación.
