# 💼 Portafolio ejecutivo

El programa debe dejar evidencia reutilizable en entrevistas, promoción interna, consultoría o creación de empresa.

## Artefactos mínimos

- Personal Leadership Operating System
- Decision journal
- One-page executive memo
- Team charter
- Role scorecard
- 30-60-90 onboarding plan
- Project charter + risk register
- Process map + SLA
- KPI tree + monthly business review
- P&L / cash / unit economics analysis
- Sales pipeline + enterprise proposal
- Go-to-market plan
- Product discovery tree + experiment
- Strategy memo
- Organization design
- Enterprise risk register
- CEO dashboard + first 100 days
- Board pack
- Capital allocation memo
- AI transformation roadmap
- Venture validation dossier
- Chile company operations dossier
- Owner dashboard
- Independence plan + final board defense

No publiques información confidencial de empleadores o clientes.
